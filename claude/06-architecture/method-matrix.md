# Method matrix (MTH-001)

One row per engineering method RhoeFlow ships. Method ids are stable and independent of the app
version (CLAUDE.md §Conventions). A method's version changes only when its result can change.
Status: **planned** (WO-02 scope, not written), **implemented** (code and tests exist),
**verified** (differential test against the oracle passes within the recorded tolerance).

Started in WO-02 Track A, 2026-10-25. Track B began the same day; status per row.

Coefficient provenance (owner decision pending): `packages/calc/src/methods/coefficients.ts`
carries the CLTD bases, color multipliers, wall-group thresholds, attic temperatures and slab
model constants transcribed from the reference engine's BSD-licensed code, whose comments
attribute them to Manual J figures. The methods take them as data; a re-derived set can
replace them under a new method version.
