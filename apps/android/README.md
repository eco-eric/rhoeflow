# RhoeFlow Android app

A Capacitor 8 shell that opens the live app at https://app.rhoeflow.pro (ADR-032, ADR-046).
Package name `pro.rhoeflow.app`: permanent once the first build is uploaded to Google Play.

## What is in here

| Path | What it does |
| --- | --- |
| `capacitor.config.ts` | App name and package, the URL the shell opens, the offline page |
| `www/offline.html` | Shown when app.rhoeflow.pro cannot be reached |
| `android/` | The Android Studio project (generated by `cap add android`, then edited: App Links, no backup, cache-only file sharing, release signing from `keystore.properties`, icons and splash) |
| `resources/` | Icon sources and the 512 x 512 Play listing icon (`play-icon-512.png`) |
| `scripts/make-icons.mjs` | Regenerates the icons from `resources/*.svg` |

What the web app does for the Android app (all in `apps/web`, inert in a browser):

- **Report PDF:** "Save or share PDF" writes the PDF to the app's cache and opens the share sheet (`components/pdf-download-link.tsx`, `lib/native.ts`).
- **Sign-in emails open in the app:** App Links for every app.rhoeflow.pro link. Android checks `https://app.rhoeflow.pro/.well-known/assetlinks.json`, which lists the fingerprints in the Worker var `ANDROID_CERT_FINGERPRINTS` (`apps/web/wrangler.jsonc`). The page then follows the link once (`components/native-shell.tsx`).
- **Play's required pages:** `/privacy` and `/delete-account` (public). Settings > Profile links to deletion.

Web changes reach phones as soon as the Worker deploys. Only changes in this folder need a new Play upload, with `versionCode` raised in `android/app/build.gradle`.

## Try it on a phone

Every pull request builds a debug APK in CI (job `android`, artifact `rhoeflow-android-debug`). Download it, copy it to an Android phone and open it (allow installs from that app when asked). The debug build is signed with a throwaway debug key, so sign-in emails keep opening in the browser until the Play build is installed.

## Build locally

Needs Node 24, pnpm, JDK 21 and the Android SDK (Android Studio installs it).

```
pnpm install
pnpm --filter @rhoeflow/android sync
cd apps/android/android
./gradlew assembleDebug      # debug APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew bundleRelease      # Play upload: app/build/outputs/bundle/release/app-release.aab
```

On Windows use `.\gradlew.bat` in PowerShell (WorkEdge's notes: `gradlew` is not found from `npx cap run`).

## Upload key (release signing)

Play re-signs the app with its own key (Play App Signing). We sign uploads with an upload key:

```
mkdir -p apps/android/android/keystore
keytool -genkeypair -v -keystore apps/android/android/keystore/rhoeflow-upload.jks \
  -alias rhoeflow -keyalg RSA -keysize 2048 -validity 10000
cp apps/android/android/keystore.properties.example apps/android/android/keystore.properties   # fill in the passwords
```

The `.jks` and `keystore.properties` are git-ignored. Keep a backup of both somewhere safe (a password manager). If the upload key is lost, Play support can reset it, but that takes days.

## First release to Play internal testing

In the EcoSource IQ LLC Play Console (the account that holds WorkEdge Pro):

1. **Create app:** name RhoeFlow, English (United States), App, Free.
2. **Internal testing > Create new release:** choose Google-generated app signing key, upload `app-release.aab`.
3. **Testers:** an email list with the Google accounts that should install it; copy the opt-in link and open it on the phone.
4. **App integrity > App signing:** copy the SHA-256 of the **app signing key** and of the **upload key** into `ANDROID_CERT_FINGERPRINTS` in `apps/web/wrangler.jsonc` (comma-separated), merge and deploy. Then sign-in emails open in the app.
5. **App content** (needed before anything beyond internal testing, quick to fill now):
   - Privacy policy: `https://app.rhoeflow.pro/privacy`
   - App access: login required; give reviewers a demo login in a test company account (no real customer data)
   - Ads: no. Target audience: 18 and over. Content rating: utility/productivity, no user-to-user chat.
   - Data safety: collects name, email, phone (account); photos and files (job evidence); addresses (customer houses, entered by the user). No location, contacts, financial or health data. Encrypted in transit. Deletion: `https://app.rhoeflow.pro/delete-account`. Processors: Supabase, Cloudflare, Resend, OpenRouteService, Esri, USGS, RentCast, WorkEdge (if connected).
   - Account deletion URL: `https://app.rhoeflow.pro/delete-account`
6. **Store listing:** short and full description, the 512 x 512 icon in `resources/play-icon-512.png`, a 1024 x 500 feature graphic, and at least two phone screenshots.

If the Play account is a personal (not organization) account, Google asks for a closed test with 12 testers for 14 days before production. Internal testing has no such rule.
